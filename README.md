# ⚡ Gemelo Digital de un Transformador Eléctrico

## 📌 Descripción del proyecto

Este proyecto presenta una investigación sobre el **gemelo digital de un transformador eléctrico** y un simulador interactivo que permite observar cómo cambia su comportamiento según el consumo de energía de las viviendas conectadas.

El objetivo es comprender cómo la simulación, el monitoreo de variables eléctricas y las alertas pueden contribuir al mantenimiento predictivo y a la detección temprana de posibles problemas.

## 🎯 Objetivos

- Comprender el funcionamiento de un transformador eléctrico.
- Simular el consumo eléctrico de diferentes viviendas.
- Observar los cambios en la corriente, la carga y la temperatura.
- Analizar el envejecimiento del aislamiento y los niveles de alerta.
- Explorar la aplicación de los gemelos digitales en el mantenimiento predictivo.

## 📂 Contenido del repositorio

### 1. Investigación en PDF
Documento teórico sobre el funcionamiento de los transformadores de potencia, sus componentes, los sensores, la arquitectura del gemelo digital y las estrategias de mantenimiento predictivo.

Archivo: `Gemelo_Digital_Transformador_de_Potencia (1).pdf`

### 2. Simulador interactivo
Simulación de un transformador de poste que permite agregar o quitar viviendas, encender y apagar aparatos eléctricos y observar los cambios en las variables del sistema.

Archivo: `Simulador de transformador de poste.html`

## 🚀 Cómo ejecutar el simulador

1. Descarga el archivo HTML desde este repositorio.
2. Ábrelo con un navegador web actualizado, como Google Chrome o Microsoft Edge.
3. Selecciona la capacidad del transformador.
4. Enciende o apaga los aparatos eléctricos de cada vivienda.
5. Observa la corriente, el porcentaje de carga, las temperaturas y las alertas.
6. Prueba los escenarios de consumo disponibles para comparar el comportamiento del transformador.

**No necesitas instalar programas adicionales para abrir el simulador.**

## 📊 Aplicaciones

Este proyecto tiene fines educativos y permite explorar conceptos relacionados con:

- Gemelos digitales.
- Ingeniería eléctrica.
- Monitoreo de transformadores.
- Simulación de cargas eléctricas.
- Mantenimiento predictivo.
- Detección de condiciones anormales.

## ⚠️ Alcance y limitaciones

El simulador utiliza un modelo matemático simplificado y valores de ejemplo. No está conectado a un transformador físico ni a sensores reales, y sus alertas no constituyen un diagnóstico técnico del equipo. Para aplicaciones reales se requieren modelos validados, datos medidos y criterios de ingeniería.
